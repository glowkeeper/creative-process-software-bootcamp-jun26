# HTML & CSS Resources

## About This Guide

The Software Development Bootcamp is designed to be self-contained.

You do **not** need any of the resources below to complete the course successfully.

However, if today's topic has sparked your curiosity, these carefully selected resources provide an excellent place to continue exploring HTML and CSS.

The aim is quality rather than quantity.

## Official Documentation

### MDN Web Docs

https://developer.mozilla.org/

MDN Web Docs is the definitive reference for HTML, CSS and modern web development.

It combines excellent explanations with practical examples and is widely used by professional developers.

If you only use one HTML and CSS resource, use this one.

### Recommended Reading

## Browser Tools

### Browser Developer Tools

Every modern browser includes powerful developer tools for inspecting and experimenting with HTML and CSS.

Learn how to:

- Inspect HTML elements
- View applied CSS rules
- Experiment with CSS changes
- Understand page layout
- Debug styling issues

If you become comfortable using your browser's Developer Tools, you'll solve many HTML and CSS problems much more quickly.

## Learning Philosophy

The most valuable HTML and CSS resources are often the ones you already have:

1. Your own application.
2. The course reference application.
3. The browser's Developer Tools.
4. The MDN documentation.

Professional developers rarely memorise HTML elements or CSS properties.

Instead, they build web pages, experiment, inspect the results, and use the documentation whenever they need it.

Confidence comes from building websites, not memorising syntax.
