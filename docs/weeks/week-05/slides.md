# Code Reading Challenge

Before opening the code...

- Where does the application start?
- Which file would you open first?
- Where does the state live?
- Which files seem most important?

---

# Components

Questions:

- How many components are there?
- Why are they separate?
- Could any be merged?
- Could any be split?

---

# State

Questions:

- Which component owns the state?
- Why does it live there?
- Which components depend upon it?

---

# Props

Questions:

- Which information is passed using props?
- Why?
- How does information move through the application?

---

# Rendering Lists

Questions:

- Where is map() used?
- Why does each item need a key?

---

# Event Handling

Questions:

- What happens when Add Task is clicked?
- Where is the function defined?
- Which component updates the state?

---

# Architecture Challenge

Suppose a client asks for:

- Search
- Priorities
- Due dates
- Dark mode

Which files would you change first?
