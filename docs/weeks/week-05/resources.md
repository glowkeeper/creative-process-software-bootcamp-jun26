As your React projects become larger, you'll spend more time working in a terminal.

Everything you need for this bootcamp has been demonstrated during the workshops, but these resources are useful if you'd like to become more confident using the command line.

## Common Commands

The following commands are useful throughout the bootcamp.

| Task | macOS / Linux | Windows |
|------|---------------|----------|
| Show current folder | `pwd` | `cd` |
| List files | `ls` | `dir` |
| Change folder | `cd folder-name` | `cd folder-name` |
| Go up one folder | `cd ..` | `cd ..` |
| Create folder | `mkdir new-folder` | `mkdir new-folder` |
| Remove folder | `rm -r folder` | `rmdir /s folder` |
| Clear screen | `clear` | `cls` |

## Challenge Yourself

Can you confidently:

- Open a terminal inside VS Code?
- Navigate between folders?
- Clone a GitHub repository?
- Create a new React project?
- Install dependencies with `npm install`?
- Start a development server?
- Build a production version of your application?
- Commit and push your changes?

If you can, you're developing the command-line skills used by professional software developers every day.

---

## Key Takeaway

Professional developers don't use the command line because it's old.

They use it because it's fast, reliable and available on every platform.
