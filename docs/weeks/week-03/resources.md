# JavaScript Resources

## About This Guide

The Software Development Bootcamp is designed to be self-contained.

You do **not** need any of the resources below to complete the course successfully.

However, if today's topic has sparked your curiosity, these carefully selected resources provide an excellent place to continue exploring JavaScript.

The aim is quality rather than quantity.

## Official Documentation

### MDN Web Docs

https://developer.mozilla.org/

MDN Web Docs is the definitive reference for JavaScript and modern web development.

It provides clear explanations, practical examples and detailed reference material that is used by professional developers every day.

If you only use one JavaScript resource, use this one.

### Recommended Reading

Read these in roughly this order:

1. **JavaScript Guide**  
   https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide

2. **Variables**  
   https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/Variables

3. **Functions**  
   https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/Functions

4. **Objects**  
   https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/Object_basics

5. **Arrays**  
   https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array

6. **Array Methods (`map()`, `filter()`, `find()`)**  
   https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array

   https://developer.mozilla.org/en-US/docs/Web/API/Document_Object_Model/Introduction

8. **Events**  
   https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/Events

These topics closely match the concepts introduced during the bootcamp.

## Browser Tools

### Browser Developer Tools

Every modern browser includes powerful developer tools for inspecting and debugging JavaScript.

Learn how to:

- View errors in the Console
- Inspect variables
- Use `console.log()`
- Explore the DOM
- Debug event handlers
- Step through your code

Learning to use Developer Tools is one of the fastest ways to become a more confident JavaScript developer.

## Learning Philosophy

The most valuable JavaScript resources are often the ones you already have:

1. Your own application.
2. The course reference application.
3. The browser's Developer Tools.
4. The MDN documentation.

Professional developers rarely memorise every JavaScript feature.

Instead, they solve problems, experiment with code, debug their applications, and use the documentation whenever they need it.

Confidence comes from writing JavaScript, debugging JavaScript, and gradually developing an understanding of how the language works.
